# Autonomous AI Delivery Robot

## Project Overview

This project is a simulation-based Autonomous AI Delivery Robot developed using Python, YOLO object detection and the A\* pathfinding algorithm.

The robot navigates through a virtual 10×10 grid environment, avoids obstacles and automatically replans its route when a dynamic obstacle blocks its path.

The project also includes a Tkinter dashboard that displays three different delivery scenarios simultaneously.

## Project Objectives

- Develop an autonomous robot simulation.
- Implement A\* for intelligent path planning.
- Use YOLO for image-based object detection.
- Detect and avoid dynamic obstacles.
- Automatically replan routes when obstacles appear.
- Compare robot performance under different obstacle conditions.

## Features

1. **AI Object Detection:** Uses YOLO to detect objects from an input image.
2. *A Path Planning:*\* Finds a route from the starting point to the destination.
3. **Dynamic Obstacle Avoidance:** Introduces obstacles while the robot is moving.
4. **Automatic Route Replanning:** Calculates a new path when the current route becomes blocked.
5. **Route Comparison:** Compares shortest and alternative routes.
6. **Three-Scenario Dashboard:** Displays no-obstacle, one-obstacle and multiple-obstacle simulations side by side.
7. **Performance Monitoring:** Tracks robot movements, replanning events and delivery status.

## Installation Instructions

### 1. Install Python

Install Python 3.10 or later.

### 2. Download the Project

Clone the GitHub repository:

```bash
git clone https://github.com/YOUR_USERNAME/autonomous-ai-delivery-robot.git
```

### 3. Open the Project Folder

```bash
cd autonomous-ai-delivery-robot
```

### 4. Install Dependencies

```bash
pip install ultralytics matplotlib numpy
```

Install any additional packages required by the project.

## Execution Steps

### Run the Dashboard

```bash
python dashboard.py
```

Click **START / RESTART COMPARISON**.

The dashboard displays three scenarios:

- No dynamic obstacles
- One dynamic obstacle
- Multiple dynamic obstacles

### Run an Individual Simulation

```bash
python main.py
```

The simulation calculates a route, moves the robot and replans when necessary.

## Project Output

The system displays robot movement, planned routes, dynamic obstacles, replanning events and delivery results.

## Limitations

- The project is a software simulation.
- YOLO processes a saved image rather than live camera footage.
- Dynamic grid obstacles are generated by the simulation.
